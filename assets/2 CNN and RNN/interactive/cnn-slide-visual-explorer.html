CNN：老师课件图的可视化交互

不要先看控制器。先看主画布里的结构：一个 filter 如何在输入体积上滑动、一个 pooling window 如何压缩空间、一个 shortcut 如何把输入直接送到残差相加点。

Slide-grounded visual主结构重绘自 CNN 1 p.14、p.16、p.29、p.43 与 CNN 2 p.73、p.75；橙色窗口、蓝色路径和数值是交互标注。

主图：同一个 5×5×3 filter 在空间上复用

当前 patch → 当前 output

蓝色网格是输入空间，橙色框是当前 receptive field，橙色小网格是复用的 filter，绿色格子是当前输出。虚线箭头表示同一组 weights 被复用到下一个位置。

静态回退：老师的核心关系是 `input volume → filter → dot product → feature map`。窗口移动时 patch 变，filter weights 不变；每个窗口产生一个 output scalar，所有 scalar 按空间位置排列成 feature map。

主图：pooling 只保留局部最强响应

当前 window → 当前 pooled value

橙色框内的局部 activation 竞争一个输出位置；绿色连线指出最大值来自哪里。输出更小，但精确位置被压缩。

静态回退：2×2 window、stride=2 把 4×4 map 变成 2×2 map。每个输出只保留局部最大值，因此减少空间尺寸，同时丢失窗口内部的精确坐标。

主图：shortcut 把 identity 保留到相加点

从输入 x 开始

左侧保留老师课件的 plain layers 对照，右侧保留 residual block 的两条路径；蓝色小球沿当前路径移动，橙色节点表示实际计算，绿色圆点表示相加。

静态回退：Plain layers 直接学习 H(x)；ResNet 让卷积层学习 residual mapping F(x)，再把 identity x 沿 shortcut 送到相加点，得到 F(x)+x。深层网络的问题是 optimization 变难，不应简单归因于 overfitting。

来源边界：结构与术语来自用户提供的 CNN 1.pdf / CNN 2.pdf；数值网格、颜色、播放路径和交互状态是教学标注，不是课件实验结果。
