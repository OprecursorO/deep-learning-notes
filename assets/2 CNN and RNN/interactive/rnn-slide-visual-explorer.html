浅蓝框是每步输入 xₜ；橙色 cell 是同一个 recurrent cell 的重复调用；蓝色圆形 hₜ 是传给下一步的 state；上方 θ 只存一份。

静态回退：每个时间步输入不同，但调用同一个 cell 和同一套 θ；hₜ 作为下一步的 hₜ₋₁。时间方向有 dependency，必须先得到前一步 state。

从 t=1 开始逐步计算

蓝色实线：前向依赖；红色动态路径：反向梯度；紫色 u/w/v 各只有一份，但接收所有时间步的梯度贡献。节点按课件 scalar BPTT example 重绘。

关键结论：总损失若为各时刻损失之和，参数梯度就是每个使用位置的贡献相加：∂L/∂w = Σₜ (∂L/∂w)|ₜ。早期状态的梯度还要穿过更多次循环转移；局部因子仅用于解释连乘趋势。

三条不同的信息流汇合成新 cell state 和 hidden state

旧记忆 → 保留/写入 → 新记忆 → 输出

蓝色粗线是 cell state 主通道；橙色 gate 控制信息通过比例；绿色节点是加法；紫色输出支路产生 hₜ。线宽随保留/写入比例变化。

静态回退：Cₜ = fₜ × Cₜ₋₁ + iₜ × C̃ₜ；hₜ = oₜ × tanh(Cₜ)。output gate 改变当前暴露的 hₜ，不直接改写 Cₜ。
