Perceptron learning：一次错误如何移动 decision boundary？

这是 Lecture 1 p.84–86 的可操作教学示意。先看一条线如何把两类点分开，再让算法逐个检查样本；只有误分类时才更新参数。

老师先讲清楚

对样本 xᵢ，模型计算 score = w·xᵢ + b，并用 sign(score) 给出 +1 或 -1。若 yᵢ·score ≤ 0，说明当前边界把它分错或刚好落在边界上，更新为 w ← w + η yᵢ xᵢ、b ← b + η yᵢ。

本页的点和参数是一个小型教学例子，不是课件中的实验结果。它用来观察课件的因果链：当前样本 → score → 是否出错 → 参数更新 → 边界移动。

静态回退：可分数据上，算法只在误分类样本处更新；随着更新，错误点会减少。含冲突点时，同一个输入附近同时出现两个相反 label，单条直线无法同时满足它们，因此有限步运行后仍可能有错误。Perceptron theorem 的“有限次收敛”前提是 data linearly separable。
