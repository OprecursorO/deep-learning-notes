Causal mask：老师讲解与互动

老师先讲清楚：训练时不能偷看答案

矩阵的行是 query 位置，列是 key 位置。自回归语言模型在位置 i 预测下一个 token 时，只能读取自己和左侧的 token，所以允许条件是 j≤i。

mask 把未来位置的 score 加上一个极小值（概念上是 −∞），softmax 后它们的权重接近 0。训练可以同时算所有 query 行，但每行都独立遵守可见性约束。

query-key 可见性矩阵

✓ 当前 query 可读取的位置× 当前 query 被屏蔽的未来位置

静态读法：主对角线及其左下方是允许读取区，右上方是未来区。当前高亮的 query 行展示该位置实际能访问的 key；其他较早行各有自己的可见范围。
